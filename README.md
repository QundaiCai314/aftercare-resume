# aftercare-resume 1.0.0

售后助手第八个 Skill：将获准保存的单件售后记录与当前核对结果进行比较，指出进度和变化，并给出安全的续办建议。

Skill 不读取整个历史目录、不操作网页、不重放旧操作，也不修改任务记录。历史执行确认固定不可复用；已发出但结果未知时，必须先核对，不能重复提交。

- [测试报告](测试报告.md)

中央接口保持 1.0.0。冲突和续办门禁字段不足时采取保守处理；本包提供未生效的候选修订，须与宿主和消费者协商后才能采用。

## 验证与限制

32个作者编写的合成任务分支覆盖26类恢复场景，186项确定性检查通过；另有12项已有代码联调、5项候选契约检查及4个独立合成试用场景。它们不是用户研究、模型成功率或真实平台测试。

实际本地 TaskSnapshot/OperationLedger 存储、多窗口事务、崩溃恢复、平台适配和生产执行宿主尚未接通，因此不宣称已经完成真实跨会话恢复。完整范围见测试报告。

## 复现

Python 3.10+ 和 `jsonschema`。从解压后的完整包目录运行：

```text
python -B -X utf8 tests/build_cases.py
python -B -X utf8 tests/run_tests.py
python -B -X utf8 tests/build_candidate.py
python -B -X utf8 tests/check_independent.py
```

现有上游检查器联调结果随包保留，但复跑需要各上游 Skill 工程，故不包含本地路径相关的集成启动脚本。源文件 SHA-256 仅用于来源记录；上游原文件不包含在包内。

发布副本移除了本机绝对路径。资料均为合成开发案例，不含真实订单、账户或售后凭证。未提供单独开源许可声明；仓库上传不会替代码添加许可。
